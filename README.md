## 🌟 آخرین تغییرات و بهبودهای اعمال‌شده در نگارش v3.0.0 (۵ نوامبر ۲۰۲۶)

1. **پیاده‌سازی دقیق الگوی فراخوانی ماموگرافی برای سی‌تی اسکن (Main Workspace CT Viewer):**
   - بارگذاری مستقیم مقاطع محوری دایکام در نمایشگر اصلی نرم‌افزار بلافاصله پس از دریافت از پکس مدال.
   - قابلیت ورق زدن مقاطع سی‌تی اسکن با غلطک ماوس (MouseWheel) و اسلایدر شماره مقطع در سایدبار هوش مصنوعی.
   - باز شدن خودکار استودیوی بازسازی سه‌بعدی (3D CT Studio) بلافاصله پس از اتمام دانلود از پکس مدال.
2. **موتور سراسری Universal DICOM Reader:**
   - خواندن بی‌نقص تمام مقاطع دایکام چه با پسوند `.dcm` و چه بدون پسوند یا با نام‌های عددی در تمام پوشه‌ها و زیرپوشه‌ها.
   - اعمال هوشمند پنجره هانسفیلد دایکام (HU Windowing) جهت تفکیک دقیق بافت نرم و استخوان.
3. **رفع نقص انتخاب پوشه محلی دایکام در استودیوی ۳D:**
   - اسکن بازگشتی (Recursive) تمام پوشه‌ها و زیرپوشه‌ها و شناسایی خودکار صدها مقطع دایکام.
4. **رفع کامل خطای صدور گزارش بالینی PDF و Word:**
   - رفع خطای `ClinicalReportModal' object has no attribute 'app'` با تعریف صحیح ارجاع والد.
   - صدور گزارش رسمی دو صفحه‌ای PDF با سربرگ بیمارستان بوعلی مریوان برای ماژول سی‌تی اسکن و درج خودکار تصویر کلیدی.
5. **رفع قطعی خطای `name 'threading' is not defined`** در استودیوی سه‌بعدی سی‌تی اسکن.
6. **افزودن لانچر مستقیم `اجرای_نرم_افزار_بوعلی.bat`** جهت اجرای فوری نسخه به‌روزشده با پایتون.

## 📖 معرفی پروژه (Overview)

**نرم‌افزار تخصصی واحد تصویربرداری بیمارستان بوعلی - آرام مصطفائی (نسخه v3.0.0)** یک پلتفرم جامع، پیشرفته و کاملاً بومی برای سیستم‌عامل ویندوز است که با تجمیع **۶ موتور قدرتمند هوش مصنوعی بالینی و پردازش سه‌بعدی** و **سامانه صدور گزارش خودکار با سربرگ رسمی بیمارستان بوعلی**، به رادیولوژیست‌ها، جراحان ارتوپدی و کارشناسان تصویربرداری در تشخیص سریع، دقیق و بی‌خطای بیماری‌ها کمک می‌کند.

این نرم‌افزار به صورت **۱۰۰٪ آفلاین** (بدون نیاز به اینترنت و بدون ارسال اطلاعات محرمانه بیماران به خارج از بیمارستان) و **بدون نیاز به کارت گرافیک مجزا (CPU-based)** روی سیستم‌های درمانی اجرا می‌شود.

## 🧠 معماری موتورهای هوش مصنوعی و پردازش تصویر (Multi-AI Architecture v3.0.0)

```
                                  ┌───► [موتور ۱] حذف استخوان و تفکیک بافت نرم ریه (Qure.ai TorchScript)
                                  │
                                  ├───► [موتور ۲] کشف و کادربندی هوشمند شکستگی‌های ارتوپدی (YOLOv8 ONNX)
                                  │
[ورودی: DICOM / رادیوگرافی / CT] ──┼───► [موتور ۳] غربالگری ۱۸ بیماری قفسه سینه و محاسبه خط‌کش CTR (DenseNet-121)
                                  │
                                  ├───► [موتور ۴] غربالگری ۴ نمایه ماموگرافی و BI-RADS با یادگیری عمیق (ResNet-50)
                                  │
                                  ├───► [موتور ۵] استودیوی بازسازی سه‌بعدی سی‌تی اسکن و چرخش ۳۶۰° (3D CT Studio)
                                  │
                                  └───► [موتور ۶] سامانه صدور خودکار گزارش بالینی (Word / PDF / HIS)
```

## 🧊 استودیوی جدید بازسازی سه‌بعدی سی‌تی اسکن (New in v3.0.0: 3D CT Reconstruction Studio)

در نسخه ۳.۰.۰، ماژول اختصاصی بازسازی سه‌بعدی اضافه شده است که مقاطع خام محوری ۲D سی‌تی اسکن را به مدل‌های باکیفیت سه‌بعدی چرخشی تبدیل می‌کند:

1. **پریست‌های تخصصی ارگان‌های بدن (Multi-Organ Presets):**
   - 🦴 **استخوان و تروما (Bone & Trauma 3D):** ارتوپدی، بررسی شکستگی‌های مچ پا، زانو، شانه و اندام‌ها
   - 💀 **جمجمه، فک و صورت (Craniofacial):** استخوان‌های صورت، اربیت، گونه و شکستگی‌های لوفور
   - 🦴 **ستون فقرات و مهره‌ها (Spine):** ارزیابی مهره‌های گردنی، پشتی و کمری و کانال نخاعی
   - 🩻 **حلقه لگن و استابولوم (Pelvic Ring):** شکستگی‌های پیچیده استابولوم و ساکروایلیاک
   - 🫀 **سی‌تی آنژیوگرافی عروق (Vascular CTA MIP):** نمایش حداکثر چگالی عروق مغزی، آئورت و اندام‌ها
   - 🫁 **راه‌های هوایی و نای (Virtual Airway):** بازسازی سه‌بعدی حنجره، نای و مجاری تنفسی
2. **چرخش تعاملی ۳۶۰ درجه با اسکرول موس (Interactive 360° Cine):**
   - اسکرول نرم موس برای چرخش سریع و روان استخوان و عضو از تمامی زوایا
3. **حذف خودکار تخت و نویزهای اضافه (Smart Bed Removal):**
   - پاک‌سازی خودکار تخت فلزی معاینه دستگاه سی‌تی اسکن
4. **خروجی مش سه‌بعدی برای پرینترهای ۳D ارتوپدی (.STL Export):**
   - قابلیت ارسال مدل شکستگی استخوان به پرینترهای سه‌بعدی جهت برنامه‌ریزی قبل از جراحی

## 🚀 راهنمای نصب و راه‌اندازی سریع در ویندوز

1. کلون ریپازیتوری یا دانلود فایل فشرده:
   ```bash
   git clone https://github.com/arammoostafaye/boali-radiology-suite.git
   ```
2. ورود به پوشه `offline_package`:
   ```bash
   cd boali-radiology-suite/offline_package
   ```
3. اجرای مستقیم نرم‌افزار جامع:
   ```bash
   run_desktop_app.bat
   ```
4. یا اجرای مستقیم و مستقل استودیوی ۳D سی‌تی اسکن:
   ```bash
   boali_3d_ct_launcher.bat
   ```
