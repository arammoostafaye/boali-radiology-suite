### ویژگی‌های کلیدی نگارش جدید (v3.0.0):
1. **پیاده‌سازی دقیق الگوی فراخوانی ماموگرافی برای سی‌تی اسکن:**
   - نمایش مستقیم مقاطع محوری دایکام در محیط اصلی نرم‌افزار.
   - ورق زدن اسلایس‌ها با اسکرول ماوس و اسلایدر شماره مقطع در سایدبار.
   - باز شدن خودکار استودیوی بازسازی سه‌بعدی پس از دریافت از پکس مدال.
2. **موتور سراسری Universal DICOM Reader:**
   - خواندن تمام فایل‌های دایکام حتی بدون پسوند یا با نام‌های عددی.
   - اعمال پنجره هانسفیلد دایکام (HU Windowing) جهت تفکیک کورتکس استخوان و بافت نرم.
3. **رفع کامل خطای صدور گزارش بالینی PDF و Word:**
   - رفع خطای والد `ClinicalReportModal' object has no attribute 'app'`.
   - صدور گزارش رسمی دو صفحه‌ای PDF با سربرگ بیمارستان بوعلی مریوان برای هر چهار ماژول.
4. **رفع خطای `name 'threading' is not defined` در استودیوی سه‌بعدی.**
5. **افزودن لانچر مستقیم `اجرای_نرم_افزار_بوعلی.bat` جهت اجرای سریع بدون نیاز به کامپایل مجدد.**

### راه‌اندازی و اجرا:
- **نصب اولیه کامل:** دریافت فایل زیپ کامل `BoneSuppressionAI-Windows-x64-Offline.zip` یا اجرای `install_and_run.bat`.
- **بروزرسانی از نسخه قبلی:** دریافت پکیج سبک `BoneSuppressionAI-v2.2-Update-Only.zip` و استخراج آن کنار نسخه قبلی، یا اجرای `apply_update.bat`.
